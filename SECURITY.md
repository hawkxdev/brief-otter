# Security reports

GitHub Private Vulnerability Reporting is the selected reporting route. Use the repository's Security tab to report a vulnerability privately.

Choose **Report a vulnerability** and provide enough sanitized detail to reproduce the problem. If the private form is unavailable, open an issue asking for a preferred private reporting channel without disclosing vulnerability details, affected account information or proof-of-concept secrets.

Never include Telegram login codes, API credentials, session strings or session files in public issues, pull requests or logs. If a real session is exposed, revoke it using the account's active-session controls before sharing a sanitized report.

There are no released or supported application versions yet. No response-time, remediation deadline or bounty is promised.
